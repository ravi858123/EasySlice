#EasySlice
Een eenvoudige slicer voor je 3D-modellen. Open een model, pas het aan en maak G-code voor je printer.
Wat kan EasySlice?
Modellen openen: STL, OBJ, PLY, OFF, 3MF, GLB/GLTF en DAE
Het model schalen, draaien en passend maken op de bouwplaat
Supports instellen
Kiezen tussen verschillende laaghoogtes of je instellingen zelf aanpassen
Een skirt of brim toevoegen
Lagen bekijken en een schatting van printtijd en filamentverbruik zien
G-code opslaan voor je printer
Starten
Download de Windows-versie en open `EasySlice.exe`.
Zelf starten vanuit Python:
```bash
pip install -r requirements.txt
python app.py
```
Let op
STEP- en IGES-bestanden worden niet ondersteund. Zet deze eerst om naar bijvoorbeeld STL of 3MF.
Controleer de instellingen en de gegenereerde G-code voordat je een print start. Test bij voorkeur eerst met een klein model.
